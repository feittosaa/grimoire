# Grimoire

**Grimoire** é um Virtual Tabletop (VTT) de código aberto, modular e personalizável, desenvolvido para oferecer uma experiência flexível para jogadores e mestres de RPG de mesa.

O projeto busca criar um ambiente independente de sistemas específicos, permitindo gerenciar campanhas, integrar anotações, adaptar sistemas de RPG e desenvolver regras próprias.

## Funcionalidades Planejadas

- **Mesa Virtual:** Mapas interativos, tokens, rolagem de dados e fichas de personagens.
- **Integração com Obsidian:** Acesso a anotações em Markdown, personagens, histórias e materiais de campanha.
- **Sistemas Personalizáveis:** Adaptação de sistemas existentes, criação de mecânicas próprias e regras da casa.
- **Arquitetura Modular:** Expansão de funcionalidades por meio de plugins e módulos configuráveis.
- **Multiplayer:** Sessões hospedadas localmente, em rede LAN ou por redes virtuais como ZeroTier.
- **Integração com Discord:** Possibilidade de jogar diretamente pelo Discord através de Activities.
- **Multiplataforma:** Suporte planejado para Windows e Linux.

## Status do Projeto

**Grimoire está em fase inicial de planejamento e desenvolvimento.**

As funcionalidades e tecnologias apresentadas poderão sofrer alterações ao longo do desenvolvimento.

## Objetivo

Criar uma plataforma de RPG de mesa flexível, extensível e independente, oferecendo aos mestres e jogadores liberdade para personalizar suas campanhas, sistemas e experiências de jogo.
